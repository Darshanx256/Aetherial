Technical Methodology

Aetherial isolates CPU performance by actively preventing web browsers from taking execution shortcuts.

  • JIT Evasion: Browsers use Dead Code Elimination to skip loops. We force calculation by accumulating a mathematically dependent verification checksum.
  • Deterministic PRNG: Uses the Mulberry32 algorithm seeded at 0xDEADC0DE to guarantee identical mathematical workloads across platforms.
  • L1 Cache Locked: The inner loop utilizes zero memory allocation. Execution is constrained entirely to CPU registers and L1 Cache to measure raw silicon speed.
  • Thermal Stability: Marathon mode calculates stability by dividing the lowest sustained floor by the peak burst. 95%+ indicates excellent cooling.
